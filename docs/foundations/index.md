# TestPilot AI — Product & Engineering Hub

**Stage:** Accepted technical baseline v0.2, 8 November 2026; restricted offline fixture implementation/evaluation now exist. See [current status](../implementation-status.md); full hardened integration remains pending. No signed commercial charter, legal certification or completed control is implied.

**Goal:** Local-first AI-assisted web testing: authorized synthetic fixture discovery, finite structured planning, deterministic execution, independent oracle verification, clean reproduction, evidence and human review. Audience remains a solo developer building an honest engineering portfolio; Alignerr selection, eligibility and ownership conditions are not established.

## Current decision

Preserve Next.js/TypeScript/Tailwind, Python/FastAPI/Pydantic, Playwright/Chromium, PostgreSQL, Redis/RQ and Docker Compose. Only fixture operation manifests grant authority; the LLM never does. A current confirmed defect requires automated verified oracle-backed reproduced evidence plus human acceptance. Public requirements are planner input; hidden benchmark answers are not.

## Milestones

1. Foundation: monorepo, project configuration, API/UI and honest worker-unavailable behavior; full run admission remains pending until capable execution exists.
2. Proved browser isolation and bounded fixture discovery/evidence.
3. Hosted planner with canonical strict schema and explicit token/spend controls.
4. Deterministic execution under immutable authorization.
5. Independent oracle verification, clean reproduction and human review.
6. Paired good/broken fixture evaluation with machine/human metrics.
7. Setup/runbook, recorded tests and walkthrough with stated limitations.

These remain a proposed seven-day sequence, not a delivery guarantee or accomplished work. Security and evidence gates cannot be waived to meet a date. Basic run history is P0; comparison, replay/export, scheduling and external integrations are deferred.
